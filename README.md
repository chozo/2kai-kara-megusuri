# 2階から目薬（プロトタイプ）

ことわざ「2階から目薬」を、そのまま 3D ミニゲームにしたスマートフォン縦画面向けの Web ゲームです。

建物の 2 階ベランダから、地上で上を向いている人の **目** に目薬を 1 滴落とします。
風向き・風速を読んで落とす位置を調整し、まばたきのタイミングも読みます。
目に入ると次のレベルへ進み、3 階 → 5 階と高くなっていきます（LEVEL 3 まで）。

> 検証したい体験：**DROP → 落下 → 水滴追跡 → 顔へ接近 → 目にスポッと入る**

外部アセットは使わず、Three.js のプリミティブ形状と Canvas で生成したテクスチャだけで作っています。
BGM・効果音も音声ファイルは使わず、Web Audio API でその場で合成しています。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| 描画 | [Three.js](https://threejs.org/) (WebGL) |
| 言語 | TypeScript |
| ビルド | Vite |
| 物理 | 自前の簡易計算（重力 + 風。物理エンジンなし） |

React などのフレームワークは使っていません。依存ライブラリは `three` のみです。

## ゲームシステム

### 流れ

```
title（タイトル画面） → aim（位置調整） → squeeze（目薬を押す・滴が膨らむ） → falling（落下） → impact（着弾） → result（結果）
  ↑                                                                                                          ├→ もう一滴 / 次のレベルで aim へ
  └──────────────────── allclear（オールクリア演出・LEVEL 3 で成功）← タイトルへ ────────────────────────────┘
```

- 起動するとタイトル画面（「２階から目薬」「風向きを読んで2階目薬をさせ！」）が出ます。**スタート**（または Space / Enter）でゲームが始まり、このとき BGM も鳴り始めます。
- **目に入る（SUCCESS）まで、風向き・風速は同じまま** です。外したら同じ風で再挑戦でき、WIND 表示に「同じ風でもう一度」と出ます。成功すると次の一滴から新しい風になります。
- 目薬の位置も前回のまま残るので、「さっきより右に 10cm」のように修正しながら狙えます。
- ページのリロードは不要です。

### レベル

| LEVEL | 高さ | 落下時間 | 1 m/s あたりの流され方 | 風速の範囲 | 奥行き方向の風の最大角度 |
| --- | --- | --- | --- | --- | --- |
| 1 | 2階 | 約 1.0 秒 | 約 23 cm | 0.6〜3.6 m/s | 25° |
| 2 | 3階 | 約 1.6 秒 | 約 54 cm | 0.5〜3.0 m/s | 13° |
| 3 | 5階 | 約 2.3 秒 | 約 118 cm | 0.4〜2.3 m/s | 8° |

- **目に入る（SUCCESS）と次のレベルへ** 進みます。結果画面に「LEVEL 2（3階）へ！」と出て、ボタンが「3階へ進む」になります。
- LEVEL 3 で成功すると **オールクリア** です。「入った！」のあと、次の演出に切り替わります。
  - 金色のフラッシュと画面の揺れ、回る光を背景に、王冠と「ALL CLEAR!!」「2階・3階・5階 ぜんぶ入った！」「○ 滴で達成」を表示（滴数はタイトル画面から数えた合計）
  - 紙吹雪の連続打ち上げと花火の連発（約 4.5 秒）、専用ファンファーレと花火の音
  - 地上の人物がバンザイしながら跳ね、カメラが人物の斜め上から左右にゆっくり回り込む
  - 約 3 秒後に **タイトルへ** ボタン。押すとタイトル画面に戻り、LEVEL 1（2階）から新しい風で始まります（クリア済みのレベルはそのまま選べます）
- 高い階ほど落下時間が長く、同じ風速でも大きく流されます。そのかわり、風速の上限と奥行き方向の角度を小さくして、ベランダから届く範囲に収めています。
- 画面左上のボタン（2階 / 3階 / 5階）で、**クリア済みのレベルに戻れます**（位置調整中のみ）。未クリアのレベルには 🔒 が付きます。
- クリア済みのレベルはブラウザ（localStorage）に保存されます。リセットしたいときは、開発者ツールで `localStorage.removeItem('megusuri-unlocked')` を実行してください。
- レベルが変わると、建物・プレイヤーを作り直し、通常カメラも高さに合わせた構図へ補間で移動します。

### 座標系

- 単位はメートル。地面 y = 0。建物の正面が z = 0 で、+Z が手前（通常カメラ側）。
- 地上の人物は z ≈ 2 に立ち、建物（-Z）の方を向いて顔を約 70° 上に向けています。

### 水滴の物理

`Droplet.step()` で固定ステップ（1/240 秒）ごとに積分します。

```ts
velocity.y -= gravity * dt;
velocity.x += wind.x * dt;
velocity.z += wind.z * dt;
position   += velocity * dt;
```

`wind` は「表示風速 (m/s) × `windAccelPerMps`」の加速度です。命中するまで一定で、ランダムな揺らぎはありません。
**同じ風・同じ位置なら必ず同じ場所に落ちる** ので、風を読めば狙えます。

LEVEL 1（2階）では、落下時間は約 1.0 秒で、横に流される量は **風速 1 m/s あたり約 23 cm** です（最大 3.6 m/s で約 83 cm）。
風向きは左右が主で、奥行き方向の成分はレベルごとに最大角度を制限しています（ベランダから身を乗り出せる範囲に収めるため）。

### 風の表示

- 画面上部に `WIND` と、通常カメラから見た向きに回転した矢印、風速（m/s）、「左へ・やや手前へ」のような説明を表示します。
- 3D 空間では、流れる白い筋・旗のたなびき（弱風では垂れる）・雲の移動で風を表しています。
- 照準や着地点の予測線は **通常プレイでは表示しません**。

### カメラ

| モード | 内容 |
| --- | --- |
| `overview` | ベランダのプレイヤー・地上の人物・高低差が同時に見える斜め俯瞰。レベルごとに構図が違う。ゆっくり揺れる |
| `follow` | DROP 後、水滴の少し手前上から追跡。外壁のサイディングや窓が上へ流れて落下速度が伝わる |
| `face` | 水滴が目の高さ + 1.1 m まで来て、顔から水平 45 cm 以内なら顔へズーム。額が画面上になる向きで目・黒目・白目・まばたきが分かる距離まで寄る |
| `ground` | 顔から遠い落下や、顔の横をすり抜けた場合は地面まで追跡 |
| `celebrate` | オールクリア時。バンザイする人物を斜め上から映し、建物にめり込まない範囲で左右にゆっくり回り込む |

モードの切り替えでは、切り替え直前のカメラ位置・注視点・画角・上方向から、新しいモードの目標へイージングで補間します（瞬間移動しません）。
顔ズーム中は時間がゆっくりになり（接近スローモーション）、成功した瞬間はさらに強いスローモーションと寄りが入ります。

### まばたき

- 1.4〜3.8 秒のランダム間隔で、0.2 秒のまばたきをします。20% の確率で連続まばたきします。
- まぶたの閉じ具合が 0.55 以上のときに目に着弾すると **まばたき！**（失敗）になります。
- まばたきはゲーム内時間で進むため、スローモーション中はまばたきもゆっくりになります。

### 当たり判定と結果

水滴の 1 ステップ分の移動線分と、頭の球（見た目より少し大きめ）の交差を調べます。
交点を頭の表面に投影し、各黒目（頭の表面に投影した位置）からの距離で判定します。

| 判定 | 条件 | 表示 |
| --- | --- | --- |
| SUCCESS | 黒目から 6 cm 以内・目が開いている | **入った！** |
| 惜しい | 黒目から 10 cm 以内（白目） | **惜しい！** |
| まばたき | 目の範囲だが、まぶたが閉じていた | **まばたき！** |
| FACE HIT | 顔の正面側 | **顔。** |
| MISS | 後頭部 / 体 / 地面 | **頭。** / **服。** / **地面。** |

成功すると、「入った！」と一緒に画面の左右下から紙吹雪が打ち上がり、上からも降ってきます（ファンファーレ付き）。

失敗時は「黒目まで ○ cm（右に ○cm・奥に ○cm ズレ）」を表示し、次の一滴の調整に使えるようにしています。
左右と奥・手前は、通常カメラから見た向きです。

### 音

ブラウザの自動再生制限があるため、**最初に画面をタップ（またはキー入力）した時点** で音が有効になり、BGM が始まります。
スタートボタンを押したときにも BGM を開始します。
右上の 🔊 ボタンでミュートできます。ミュートは保存しないため、**ページを開くたびに BGM ありで始まります**。

| タイミング | 音 |
| --- | --- |
| 常時 | BGM（C–Am–F–G の 4 小節ループ）と、風速に応じた強さの風の音 |
| DROP | 目薬を押す「きゅっ」→ 滴が離れる「ぽつっ」→ 落下中の風切り音（BGM は小さくなる） |
| 顔へズーム | スローモーションに入る「キーン」 |
| 目に入った | 「ぽちゃん」→ 結果表示でファンファーレ + 紙吹雪 |
| オールクリア | 長いファンファーレ + シンバル、花火の「ドン…パチパチ」 |
| 惜しい / まばたき | 着弾の「ぺちっ」→ 下がる 2 音 |
| 顔・頭・服 / 地面 | 「ぺちっ」/「ぴちゃっ」→ ゆるい「ぶっぶー」 |
| もう一滴 | ボタン音 |

## 主要パラメータの変更方法

すべて `src/config.ts` の `CONFIG` にまとまっています。

| 目的 | パラメータ |
| --- | --- |
| 重力 / 落下時間 | `physics.gravity`, `physics.initialVelocity` |
| 風の効き具合 | `physics.windAccelPerMps` |
| 風速の範囲（レベルごと） | `LEVELS[n].windMin`, `LEVELS[n].windMax` |
| 奥行き方向の風の最大角度（レベルごと） | `LEVELS[n].windMaxDepthAngleDeg` |
| 階の高さ | `LEVELS[n].floorHeight`（ベランダ床 = `(floor - 1) × floorHeight`） |
| 通常カメラの構図（レベルごと） | `LEVELS[n].overviewPos`, `LEVELS[n].overviewLook`（省略すると2階の構図を高さに比例して拡大） |
| 遊べるレベル | `LEVELS[n].playable` |
| 進行状況の保存 | `saveProgress` |
| 手の高さ・移動範囲・ドラッグ感度 | `player.*` |
| 水滴の見た目の大きさ / 溜め時間 | `droplet.visualRadius`, `droplet.squeezeTime` |
| 目の当たり判定 | `hit.pupilHitRadius`（SUCCESS）, `hit.eyeHitRadius`（惜しい）, `hit.headHitRadius` |
| 顔・目の見た目 | `target.headRadius`, `target.eyeRadius`, `target.pupilRadius`, `target.eyeSpreadDeg` |
| まばたき | `blink.intervalMin/Max`, `blink.duration`, `blink.closedThreshold`, `blink.enabled` |
| カメラ | `camera.*`（通常カメラ位置、追跡オフセット、顔ズーム開始高さ、遷移時間など） |
| スローモーション | `time.approachSlowMo`, `time.successSlowMo`, `time.successSlowMoDuration` |
| もう一滴ボタンが出るまで | `time.retryButtonDelay` |
| オールクリア演出 | `time.allClearDelay`（演出が始まるまで）, `time.allClearDuration`（花火・紙吹雪の長さ）, `time.allClearButtonDelay`（タイトルへボタンが出るまで） |
| 音量・BGM のテンポ | `audio.master`, `audio.bgm`, `audio.sfx`, `audio.bgmTempo` |
| 紙吹雪のオン・オフ | `effects.confettiOnSuccess` |

### 難易度の目安

- **簡単にしたい**：`hit.pupilHitRadius` を 0.08 程度に上げる / `blink.enabled = false` / 各レベルの `windMax` を下げる。
- **難しくしたい**：`physics.windAccelPerMps` を上げる / `blink.intervalMin` を下げる / 各レベルの `windMaxDepthAngleDeg` を上げる。
- 風を強くしたり移動範囲を狭めたりするときは、最大の風でも目薬が届くか確認してください（5階で最大 2.3 m/s のとき、横に約 2.6 m ずらす必要があります。`player.minX/maxX` は ±3.1 m）。

## デバッグモードの使い方

次のいずれかでオン・オフを切り替えます。

- URL に `?debug` を付ける（例：`http://localhost:5173/?debug`）
- **D** キー

画面上の DBG ボタンはありません（削除済み）。

表示内容:

- 水滴の軌跡（赤線）
- 現在位置から落とした場合の予測軌道（水色の点線）。**デバッグ専用** で、通常プレイでは表示しません
- 当たり判定領域：黒目（緑。閉じている間は赤）、白目（黄）、頭（青）のワイヤーフレーム
- 風ベクトル（ノズル上の青い矢印）
- FPS・状態・時間倍率・風・ノズル座標・水滴座標・速度・まぶたの開閉

その他:

- `?notitle` を付けると、タイトル画面を飛ばしてすぐ遊べます（`?debug&notitle` のように組み合わせ可）。
- `?speed=0.2` のように付けると、ゲーム全体を 0.2 倍速で動かしてカメラ演出を確認できます。
- 開発サーバー（`npm run dev`）では、ブラウザのコンソールから `window.game` を操作できます。

### 1. プロトタイプの実装

依頼：Three.js で「2階から目薬」のプレイアブルなプロトタイプを作る。見た目より **DROP → 落下 → 水滴追跡 → 顔へ接近 → 目に命中** の体験を優先。照準・予測線は出さない。

- 構成は Vite + TypeScript + Three.js のみ（React・物理エンジンなし）。外部アセットなしで、形状はプリミティブ、テクスチャは Canvas で生成
- 実物どおりの重力だと手から目まで約 0.7 秒で落ちてしまうため、重力を 4.5 m/s² に弱めて落下を約 1 秒にした。さらに顔の手前でスローモーションにして、目に入る瞬間を見えるようにした
- 1 cm 単位の狙いは厳しいため、人物をデフォルメして頭と目を大きめにした
- ブラウザで確認しながら次を直した
  - 通常カメラで、プレイヤーが WIND 表示に隠れていた → 構図を調整
  - 顔ズームで顔が逆さまに映り、水滴も画面外に出ていた → 額の方向をカメラの「上」にし、水滴が画面上方から目へ向かう構図に変更
  - 顔の横をすり抜けた水滴を見失う → 目の高さより下に落ちたら地面まで追跡するモードを追加
  - 学習しづらい → 外れたときに「黒目まで ○cm（右に ○cm・奥に ○cm ズレ）」を表示し、当たり判定も少し広げた（黒目 5→6 cm、白目 8.5→10 cm）
  - ドラッグの感度が高すぎる → 下げた

### 2. 紙吹雪・BGM・効果音

依頼：目に入ったら紙吹雪で祝う。BGM と効果音を鳴らす。

- 紙吹雪は、カメラ位置に関係なく必ず見えるよう、3D ではなく画面に重ねた 2D Canvas で描く
- 音は音声ファイルを使わず Web Audio API で合成。ブラウザの自動再生制限のため、最初のタップで音を有効化する。ミュートボタンを追加

### 3. 命中するまで同じ風

依頼：毎回風を変えるのではなく、命中するまで同じ風向き・風速にする。

- 外している間は風を変えず、WIND 表示に「同じ風でもう一度」と出す。目薬の位置も残るので、ズレ表示を見て少しずつ修正するゲームになった
- 「惜しい！」「まばたき！」も失敗扱いで、同じ風が続く

### 4. LEVEL 3（5階）まで

質問：「LEVEL 1 と書いてあるが、どうなったら LEVEL 2 になるのか」→ 当時はレベルアップがなく、表示だけだった。依頼を受けて LEVEL 3 まで実装した。

- 成功で次のレベルへ進む。クリア済みのレベルには左上のボタンで戻れ、進行状況は localStorage に保存する
- 階が上がると落下時間が延び、同じ風速でも大きく流される（1 m/s あたり 2階 23 cm / 3階 54 cm / 5階 118 cm）。風速の範囲と奥行き方向の角度はレベルごとに設定し、ベランダから届く範囲に収めた
- 最大の風で必要になる位置を計算で確かめたところ、奥行きがわずかに届かなかった（必要 2.44 m、範囲 2.40 m）。そこで奥行きの範囲を 2.55 m、左右を ±3.1 m に広げた
- 5 階の通常カメラでプレイヤーが WIND 表示に隠れたため、構図を個別に調整した

### 5. タイトル画面

依頼：最初にタイトル画面。「２階から目薬」「風向きを読んで2階目薬をさせ！」と表示する。

依頼：プロジェクト名「2kai-kara-megusuri」で Cloudflare にデプロイ → その後 `game.chozo.net/2kai-kara-megusuri/` で公開するよう依頼。

- まず Workers の静的アセット配信で `2kai-kara-megusuri.<account>.workers.dev` に公開した
- 次に game.chozo.net の既存ゲーム（`/shusse-game/`、`/typhoon-umbrella/` など）に合わせた構成に変えた
  - ルートを `/2kai-kara-megusuri` と `/2kai-kara-megusuri/*` の 2 つにした
  - ビルドの出力先を `dist/2kai-kara-megusuri/` にした
  - `workers_dev: false` にし、workers.dev の URL は無効にした
- ルート登録の直後は数十秒ポータルのページが返ったが、反映待ちだった。他のゲームとポータルに影響がないことも確認した

### 7. オールクリア演出とタイトルへの復帰

依頼：オールクリアの演出をもっと派手に。オールクリアしたらタイトル画面に戻る。

- 演出の内容
  - 金色のフラッシュ・画面の揺れ・回る光・王冠・「ALL CLEAR!!」
  - 紙吹雪の連続打ち上げと花火
  - 専用ファンファーレ
  - バンザイして跳ねる人物と、回り込むカメラ

- 「ALL CLEAR!!」の文字が画面からはみ出し、喜ぶ人物もボタンに隠れていた → 文字を小さくして上に寄せ、ボタンを画面下に移した

### 8. DBG ボタンの削除と BGM のデフォルト

依頼：ゲーム画面の「DBG」を消す。デフォルトは BGM ありにする。

- 右上の DBG ボタンを削除し、🔊 ボタンをその位置に上げた。デバッグ表示は D キーと `?debug` で引き続き使える
- ミュートの設定を localStorage に保存していたため、一度ミュートすると次に開いたときも無音だった → 保存をやめ、毎回 BGM ありで始まるようにした
- スタートボタンを押した時点でも BGM を開始するようにした
- 型チェック・ビルドと、公開版に変更が反映されていることは確認した。ブラウザでの見た目と音は未確認

### 確認の方法と、まだ確認できていないこと

- 各段階で、型チェック・ビルドとブラウザでの表示を確認した
- 確認用のブラウザのタブが裏に回っていて描画ループが止まるため、ゲームを 1 フレームずつ手動で進め、各場面を静止画で確認した
- そのため、次はまだ **実機で確認できていない**
  - 実時間でのテンポや操作感
  - 紙吹雪・花火の動き
  - BGM・効果音の聞こえ方
- game.chozo.net トップ（ポータル）のリストには、このゲームへのリンクをまだ追加していない。ポータルは別の Worker で配信されている

## 今後の拡張案

### レベル（高さ）の追加

`config.ts` の `LEVELS` に LEVEL 1〜9（2階 → 3階 → 5階 → 10階 → 20階 → 超高層ビル → タワー級 → 飛行機 → 宇宙）を定義済みです。
遊べるのは LEVEL 1〜3 です（`playable: true`）。LEVEL 4 以降は `playable: true` にすれば進めるようになります。

高さはすべて `floor × floorHeight` から計算しているため、レベルを切り替えると次のようになります。

- `Building` がその階数ぶんの外壁・窓を生成する
- 手の高さ（`handY()`）が上がり、落下時間が長くなる
- 同じ風速でも大きく流される
- 追跡カメラで流れる壁が長くなる

ただし、10階以上は落下時間が 3 秒を超え、横に流される量も非常に大きくなるため、そのままでは遊びにくくなります。

さらに拡張するなら、次のようなものが考えられます。

- 高さに応じた空気抵抗・終端速度（落下時間が極端に長くならないように）
- 高度ごとに風が変わる層構造（上空は強風、地上付近は弱風）
- 高高度ではカメラの FOV 変化・ブラー・雲の突き抜けなどの演出
- 超高層以上では建物の代わりに雲海・機体・大気圏の背景に差し替え
